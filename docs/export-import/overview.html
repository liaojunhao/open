导出与导入

设计稿的读写与出图都集中在这里。JSON 负责「状态往返」；图片 / PDF / 云渲染负责「交付物」。

我该看哪篇？​

需求文档
保存 / 恢复设计稿（JSON）Store · 场景与导入导出
客户端导出 PNG / JPEG / WebP同上 · 导出图片
客户端导出 PDFPDF 导出
大尺寸 / 高清超出浏览器限制大尺寸 & 高清导出
托管服务端出图（按量）云渲染 API
自建 Node 无头渲染服务端图像生成
Photoshop PSD → 可编辑稿（规划中）PSD 导入

两条路径​

编辑器（浏览器）
  ├─ store.toJSON() / loadJSON()     → 存盘、协同、模板
  ├─ store.toDataURL() / saveAsPDF() → 预览、小图、轻量交付
  └─ 云渲染 / Node                    → 大图、批量、印刷级

开源 SDK 已覆盖客户端导入导出；超大图与批量出图请走云或自建服务端（见定价页 Cloud & AI）。
