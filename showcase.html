用 Ydesign 能做什么？

Ydesign 不是一个 SaaS，而是一套帮你构建自家设计编辑器的 SDK。下面列出的是一些典型的应用场景，以及 Ydesign 在其中能替你解决的问题。

🎨

社交媒体海报工具

📖 场景

用户在一张海报模板上快速替换文字 / 配色 / 头图，一键导出多种尺寸。

😣 痛点
  • Canva 类 SaaS 月费高、图片要托管在对方服务器，隐私顾虑
  • 自研画布编辑器坑太多（撤销/重做、字体加载、导出精度）
  • 需要按不同平台批量生成多套尺寸
✨ Ydesign 如何解决
  • ✨ 开箱即用的完整 UI，1 小时就能起步
  • ☁️ 云渲染 API 支持批量导出，一次请求生成多张
  • 🎯 素材 / 字体 / 模板接口可完全接到自家后端
完整编辑器示例云渲染 API
👕

T 恤 / 手机壳自助定制

📖 场景

电商详情页内置"自己设计"按钮，用户点击后在画布区域排版文字或上传图片，下单时生成可印刷的高清 PNG。

😣 痛点
  • WebView 内表现要稳定（移动端手势）
  • 导出需要透明背景 + 300dpi 印刷级分辨率
  • 要能和订单系统联动，设计稿可存可复现
✨ Ydesign 如何解决
  • 📱 内置移动端断点，手势适配不用你写
  • 🖨️ 透明背景 + 4× multiplier 导出直通印刷厂
  • 💾 store.toJSON() 一键保存设计稿，下次打开不变形
T 恤设计器示例Ydesign Button 弹窗集成

书籍 / 唱片封面在线设计

📖 场景

出版 / 独立创作者在浏览器里完成书封平面设计，左边编辑右边 3D 书本样机实时预览，满意了直接下单印刷。

😣 痛点
  • 平面设计稿要"所见即所得"到 3D 样机
  • 印刷物料的出血位、CMYK、DPI 容易算错
  • 字体差异导致实际印刷和屏幕预览不一致
✨ Ydesign 如何解决
  • 👁️ reaction + multiplier: 0.3 做实时预览，不卡顿
  • 📏 内置出血位 + 单位换算（mm / in / pt / px）
  • 🔤 字体一致性指南 + 服务端归一化建议
书封编辑器示例字体一致性

证件照 / 智能抠图应用

📖 场景

用户上传生活照，选择"一寸 / 二寸 / 护照尺寸"后 AI 自动抠背景 + 补底色 + 裁切到规定尺寸，直接下载打印。

😣 痛点
  • AI 模型抠图结果需要人工微调
  • 不同国家的证件尺寸规范差异很大
  • 导出要自带打印参考线 / 拼版
✨ Ydesign 如何解决
  • 🎯 AI 消除笔（涂抹 / 框选 / 圈选）修正抠图边缘
  • 📐 内置证件照面板，一键切换常用规格
  • 🖨️ 云渲染 API 支持拼版导出
内置证件照面板

企业内部营销物料平台

📖 场景

品牌 / 市场 / HR 上百号人每天都要出各类营销图，但设计师只有三个。搭一个内部工具：模板由设计师预制，业务方只负责替换标题 / 日期 / 头像，自助导出。

😣 痛点
  • 设计师做 10 张模板，业务方做 1000 张物料
  • 要锁定品牌元素（颜色、字体、Logo 不能被误改）
  • 需要和内部素材库 / SSO / 权限系统打通
✨ Ydesign 如何解决
  • 🔒 元素锁定能力（LockHandler），关键设计保护
  • 🧩 侧边面板 / 工具栏完全可替换为内部业务组件
  • 🔌 setBaseURL / setAPI 一键接入自家后端
定制化setAPI 后端接入
🤖

AI 批量素材生成

📖 场景

电商平台的商品图运营人员，用表格填好 SKU 名 + 卖点文案，提交后系统自动套模板生成几千张差异化商品图，批量上架。

😣 痛点
  • 人工 1 天只能做 50 张，总量上不去
  • 需要在服务端生成图片，而不是让运营"一张一张导"
  • 图片里要用到自定义品牌字体
✨ Ydesign 如何解决
  • ☁️ 云渲染 API 的 /api/render/image 原生支持批量
  • 🔤 请求体 fonts 数组按 URL 声明字体
  • ⚡ 单次最多 8× multiplier，印刷 / 电商都够
云渲染 API
📱

活动 / 营销落地页海报生成

📖 场景

运营同学上活动页时会顺手生成一张分享图，走 Ydesign Button iframe 模式，H5 页面一行 script 接入，无需后端改造。

😣 痛点
  • H5 活动页技术栈五花八门，想接入编辑器但不想重构
  • 活动结束就下线，集成成本要压到最低
  • 只需要"做一张图 + 保存就行"，不要完整编辑器 UI
✨ Ydesign 如何解决
  • 🚀 Ydesign Button —— 一行 <script> 弹窗集成
  • 🧩 sections 参数按需裁剪面板
  • 💨 用户点"完成"后通过 onPublish 回调拿到图片
Ydesign Button 集成
📦

包装 / 标签设计

📖 场景

白牌商家把商品运营 SOP 做到极致：选盒型 → 选底纹 → 拖 Logo → 拖条码/二维码 → 下单印刷，工厂按 JSON 出物料。

😣 痛点
  • 条码 / 二维码需要可编辑 + 实时重新生成
  • 物料要多 SKU 批量生成，不能一张一张画
  • 印刷厂需要 JSON + 高清 PDF 双份
✨ Ydesign 如何解决
  • 🔲 条形码 / 二维码示例（svgToURL + custom 字段）
  • 📦 sceneHandler.importFromJSON 批量加载 JSON 模板
  • 🖨️ 云渲染 API 生成印刷级高清图
二维码示例条形码示例
✍️

合同 / 证明文件签发

📖 场景

培训机构给学员签发证书、租房平台签发电子合同：模板固定，批量生成个性化 PDF，用户还能在线签名。

😣 痛点
  • 模板里要动态替换姓名 / 日期 / 证件号
  • 要支持手写签名，导出 PDF 留存
  • 生成后的文件要防篡改
✨ Ydesign 如何解决
  • 🖊️ 手写签名示例（react-signature-canvas 集成）
  • 📄 A4 尺寸 + 单位换算直通 PDF 印制
  • ☁️ 云渲染服务端批量生成，不依赖客户端
手写签名示例
📊

在线演示稿（PPTX）编辑

📖 场景

企业内训 / 教育平台 / 销售工具的"网页版 PowerPoint"：浏览器里导入 .pptx → 按页编辑 → 导出回 .pptx 或直接放映，不依赖 Office。

😣 痛点
  • 原生 PPT 客户端重、装机成本高、跨平台不一致
  • 多人协作时，PPTX 文件在企业微盘里互相覆盖
  • 出差 / 移动端要改一页 PPT 时找不到电脑
✨ Ydesign 如何解决
  • 📚 多页场景（SceneHandler）天然适配幻灯片模型
  • 🔌 PPTX 解析 / 导出通过扩展 Handler 接入
  • 📱 内置移动端断点，手机也能改 PPT
