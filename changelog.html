更新日志

Ydesign 由多个独立发布的包组成，每个包都按自己的节奏迭代。本页只汇总主要能力变更，琐碎修复与依赖 bump 见各包 Git 历史。

📦 版本号遵循 语义化版本（SemVer）。从 v1.0 开始，公共 API 的破坏性变更会通过主版本号体现。

包npm当前版本状态
@ydesign/core@ydesign/core0.4.4公开预览
@ydesign/editor-store@ydesign/editor-store0.3.0公开预览
@ydesign/react-editor@ydesign/react-editor0.8.2公开预览
@ydesign/vue-editor————规划中

目前所有公开包仍处于 0.x 阶段，部分接口可能随反馈调整。v1.0 稳定版将与博客 《Ydesign SDK v1.0 正式发布》 一起发布。

@ydesign/core​

画布渲染核心，封装 Fabric.js v6，面向开发者的零 UI 依赖库。

0.4.4​

Patch Changes

  • 旋转控件样式优化：
    • 旋转柄改为稿定风格白底圆钮 + Lucide refresh-ccw 图标，隐藏连接竖线
    • hover / 拖转时显示 Lucide rotate-ccw 自定义光标
    • 裁剪退出后恢复控件时走最新 createControls（带上上述补丁）

0.4.3​

Patch Changes

  • cbaf0b1: 旋转交互与工具栏角度编辑：
    • @ydesign/core：扩展默认 mtr，按住 Shift 旋转按 10° 吸附（走 Fabric snapAngle + rotationWithSnapping，避免锚点漂移）；拖转时在旋转柄旁显示角度浮层；新增 objectsHandler.setAngle()，输入改角统一走 rotate() 绕中心旋转。
    • @ydesign/react-editor：顶栏新增可编辑角度输入（AnglePicker）；将占位的「移除背景 / 消除笔」移出内置图片工具栏，改由业务通过 components / extendToolbar（如 demo custom-toolbar）注入。

仅记录主要能力变更；琐碎修复与依赖 bump 不收录。完整提交历史见 Git。

0.4.2​

  • HistoryHandler 新增 exportStacks / importStacks，支持按页导出与恢复画布 undo/redo 栈，供多页统一撤销时间线使用。

0.4.0​

  • 新增多页编辑器底层：SceneHandler 页面切换与缩略图；历史初始化时发出 UI 状态事件。

0.3.0 （2026-06-22）​

破坏性变更：移除 nanoid 重导出，请改用 generateObjectId()。

  • GuidelinesHandler：智能参考线改为两阶段触发（先显示提示，再吸附）；每轴只吸附最近候选。
  • 新增 generateObjectId()；fabric 升级至 ^6.9.1。

0.2.1 （2026-05）​

  • RulerHandler：标尺 + 可拖参考线（刻度自适应、拖回标尺删除、对持久化透明）。

0.2.0 （2026-04）​

  • InpaintHandler：橡皮擦模式、笔画级撤销/重做、inpaint:status、replaceTargetImageSrc。

0.1.9 （2026-03）​

  • InpaintHandler：涂抹 / 框选 / 圈选三种模式，可导出 mask。
  • ImageStrokeHandler：图片虚线 / 内外描边。

0.1.x​

  • 首批 Handler 体系落地（Workarea / Zoom / Objects / History / Scene / Crop / Guidelines 等）与 Editor 事件总线。

@ydesign/editor-store​

框架无关的编辑器业务状态：MobX-State-Tree store + Project 业务层。

0.3.0​

  • 多页能力增强：文档 + 画布统一撤销时间线；loadJSON 支持 replace / append / replace-page；切页与 append 时缩略图防竞态；新增 saveAsImages 多页图片导出（ZIP）。

0.2.0​

  • 新增多页：pages API、DesignDocument 加载 / 导出、草稿缩略图。

0.1.0​

  • 首次发布：框架无关的 MobX-State-Tree Store，供 react-editor / vue-editor 共享。

@ydesign/react-editor​

官方 React 编辑器 UI 层，内置 shadcn 组件并基于 MobX + mobx-state-tree。

0.8.2​

Patch Changes

  • cbaf0b1: 旋转交互与工具栏角度编辑：

    • @ydesign/core：扩展默认 mtr，按住 Shift 旋转按 10° 吸附（走 Fabric snapAngle + rotationWithSnapping，避免锚点漂移）；拖转时在旋转柄旁显示角度浮层；新增 objectsHandler.setAngle()，输入改角统一走 rotate() 绕中心旋转。
    • @ydesign/react-editor：顶栏新增可编辑角度输入（AnglePicker）；将占位的「移除背景 / 消除笔」移出内置图片工具栏，改由业务通过 components / extendToolbar（如 demo custom-toolbar）注入。

  • Updated dependencies [cbaf0b1]

    • @ydesign/core@0.4.3

仅记录主要能力变更；琐碎修复、旧 UI 包迁移细节与依赖 bump 不收录。完整提交历史见 Git。

0.8.1​

Patch Changes

  • Fix missing main entry type declarations (app.d.ts not emitted).

0.8.0​

  • 多页体验：模板落点弹窗（单选 + 确认）；
  • Pages 缩略图尺寸优化；
  • 工具栏添加文字下拉；
  • 撤销/重做统一走 store 时间线；
  • DiscreteSlider 离散档位滑块。

0.7.0​

  • UI 层稳定为内置 shadcn 组件与语义 CSS 变量；内置主题系统（ThemeSwitcher，多套预设）。
  • 修复多页切换时图片裁剪状态未重置。

0.6.0​

  • 新增多页 UI：底部 Pages 时间轴，切页时与撤销/重做状态同步。

0.5.0​

破坏性变更：业务壳迁出 SDK。

  • 将 project、topbar、业务 API、证件照 / 消除笔等业务面板迁出，仅保留画布 UI 骨架与 Section 扩展机制。
  • 移除 /project、/topbar 及 setBaseURL / setAPI；新增 Section.nonClosable 等扩展点。

0.3.0 （2026-06）​

  • 构建迁移至 Vite（多入口 ESM + UMD bundle）；@ydesign/react-editor/bundle 可供 CDN 使用。

0.2.9 （2026-05）​

  • <RulerButton />：画布标尺与参考线开关。

0.2.8 （2026-04）​

  • 消除笔面板：橡皮擦、撤销/重做；圈选体验对齐套索手感。

0.1.x​

  • 首版编辑器 UI：SidePanel（模板 / 文字 / 图片等）、动态 Toolbar、Workspace、MST Store、i18n 与字体管理。
